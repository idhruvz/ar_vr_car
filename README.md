## Project Overview

An augmented reality vehicle visualization prototype built using
Unity and Vuforia. The application detects an image target and
renders a 3D vehicle model in augmented reality.

## Development

This project was developed as an academic prototype and adapted
from an existing Vuforia implementation.

Original reference:
https://github.com/soumya-maheshwari/Vuforia_App
